# Тестовое окно города

Добавляет кнопку «Тест» в нижнюю панель оверлея города. Кнопка и окно используют классы и цвета текущей темы сайта. Окно закрывается кнопкой или Escape. Патч ожидает появления `#gu-hud .gu-main` и повторно добавляет кнопку при пересоздании панели.

Для проверки откройте город авторизованным персонажем, нажмите «Тест» и закройте окно. Отключение: `enabled: false` в `patch.json` и перезапуск приложения; `--safe-mode` отключает все патчи.
