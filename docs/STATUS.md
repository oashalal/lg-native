# Текущее состояние

Дата: 2026-11-17. История изменений находится в [CHANGELOG.md](CHANGELOG.md).

- Каркас Electron, перехват версионированных файлов, кэш, safe mode и отчёты патчей реализованы. Кэш ограничен 256 МиБ и вытесняет записи по времени последнего доступа.
- Движок поддерживает CSS, source, ограниченные AST и runtime-патчи; native-патчи остаются заглушкой. Runtime в мире страницы внедряется через `/site/app.js`; отсутствие файла отражается в отчёте.
- Настройки патчей хранятся в профиле; сетевые runtime-патчи работают в отдельных изолированных мирах с проверкой полномочий.
- Dry-run проверяет source/AST на доступных файлах снапшота. Снапшот `86794a1329` неполный: 61 версионированный файл отсутствует. Реестр совместимости ещё не реализован.
- `LGX` в мире страницы нуждается в переработке и проверке в Electron: `version()` и `settings()` пока заглушки.
- Мультиаккаунт, полноценные нативные функции, CI и хранение серверных токенов не реализованы.
- OAuth с реальной сессией, WebGL, SSE и показатели производительности требуют ручной проверки; результаты разведки описаны в [BASELINE.md](BASELINE.md).
