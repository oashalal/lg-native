# История изменений

## 2026-11-17 — Этап 2.4

- Ограничен page bridge: вызовы уведомлений проверяются по кадру, длине и частоте; публичный отчёт не содержит внутренних путей.
- Настройки page world фильтруются по `settingsSchema`; закрытые и секретные поля остаются в main.
- `tools/dryrun --smoke` запускает Electron на локальной фикстуре и записывает результаты CSS/runtime в матрицу.
- `tools/snapshot` скачивает версионированные файлы с защищённой сессией, проверяет редиректы и утечки cookie.
- Добавлена конфигурация сборки Linux Flatpak.
- Исправлена передача декодированных ответов ресурсов и MIME-типов из кэша.

## 2026-11-17 — Этапы 2.1–2.3

- Исправлены кэш, отчёты и линтинг, добавлен реестр совместимости и автоутверждение dry-run.
- LGX перенесён в мир страницы; добавлены `version()`, `settings()`, хуки, живые ссылки и Electron e2e.
- Настройки патчей сохраняются в профиле, а нативные окна получают тему сайта.

## 2026-11-16 — Основа проекта

- Добавлены Electron-каркас, сетевой перехват, дисковый кэш, движок патчей, safe mode, отчёты и настройки.
