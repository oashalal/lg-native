# BASELINE этапа 0

Автоматический замер должен выполняться на машине с дисплеем командой:

```bash
xvfb-run -a pnpm start -- --channel=5opka
```

Встроенный сценарий замеров ожидает ручной проверки страницы: фиксируются `domContentLoaded`, первая отрисовка, время до интерактивности, `WebSocket`/SSE события и наличие WebGL. Без авторизации ожидается публичная разметка; вход Twitch здесь не выполнялся.

## Ручная проверка Twitch (ждёт ручной проверки)

1. Запустите приложение без `--safe-mode` и откройте `/c/5opka/`.
2. Нажмите штатную кнопку входа Twitch, завершите OAuth в разрешённом окне и вернитесь в приложение.
3. В DevTools/логе убедитесь, что сессия держится HttpOnly-cookie, а URL `/auth/*` и редиректы не проходят через кэш.
4. Для авторизованного героя проверьте подключение `/ws`; отключите WebSocket в DevTools и убедитесь, что SSE/поллинг продолжает работать.
5. Откройте вкладку с Pixi/WebGL, проверьте canvas и popup, затем зафиксируйте времена в этом файле.

Статус ручной проверки: переход OAuth до страницы Twitch и WebSocket проверены; возврат OAuth с реальным аккаунтом после последнего изменения ещё не автоматизирован. WebGL и точные времена замера в этот файл не заносились. Отчёт применения патчей доступен в Chromium DevTools и журнале из меню трея. Подробное состояние и план находятся в [STATUS.md](STATUS.md).
